# System Access Requests and Approval Rules

This policy explains how staff get access to PickleHub systems and who must approve each kind of access. It follows the principle of **least privilege**: people get only the access their current job needs, for only as long as they need it.

## How to request access

1. Ask DinkDesk to "request access" or email `it-help@picklehub.example`. DinkDesk creates an **Access Request** ticket.
2. Give the following details:
   - The system and the role you need (see the table below).
   - The branch, if the system is branch-specific.
   - The business reason, in one or two sentences.
   - Whether access is permanent or temporary, and the end date if temporary.
3. The ticket is sent to the required approvers. You can follow its status in DinkDesk.
4. IT sets up access within **2 business days after the last approval** (P3 target, KB-024).

Requests made by a manager on behalf of a new hire follow the same steps; the manager's request counts as the first approval.

## Rules that always apply

- **No self-approval.** If you are the approver for your own request, the next person up approves it (for example, a branch manager's own HubWatch request goes to the Operations Head only).
- **No approval by chat message.** Approvals are recorded in the ticket so they can be audited. A screenshot of a chat saying "approved" is not accepted.
- **DinkDesk does not approve access.** It can create and track the request but cannot grant permissions.
- **Access follows the job.** When you move to another role or branch, your manager must request removal of access you no longer need.
- **Quarterly review.** Each quarter, branch managers confirm the list of people with access to CourtBook, DinkPOS and HubWatch for their branch. Unconfirmed access is removed.

## Urgent access

If access is needed the same day for the club to operate (for example, a covering cashier has no Cashier ID and no one else is on shift), the branch manager can call the Service Desk on extension 4357. The approval still has to be added to the ticket afterwards.
